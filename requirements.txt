# Dependencias de RUNTIME de la Databricks App (change C9 web-ui-minimalista).
# Este archivo es el que instala el contenedor de la App al desplegarse; desde
# C9 queda separado de las dependencias de la suite local, que viven en
# requirements-dev.txt (proposal.md - What Changes; design.md D5).
#
# Reglas del contenedor (ver tests/unitarias/test_ui_dependencias.py):
# - NO declarar pytest, pyspark, delta-spark ni databricks-connect: son solo de
#   la suite local, y el contenedor no necesita un Spark local. Desde el change
#   `app-broker-identidad-ejecucion` (F2) el SQL OBO se ejecuta por la
#   Statement Execution API (scope `sql`), por lo que Connect ya no forma parte
#   del runtime de la App.
#
# Regla del proyecto: la IA no instala nada en la Mac sin aprobación expresa
# del humano. Ver README.md -> "Estándar de desarrollo" -> "Prohibición de
# instalación por la IA".

# streamlit: framework de la interfaz web (design.md D1). Databricks Apps
# documenta el arranque `streamlit run app.py` y el acceso al header OBO con
# `st.context.headers.get("x-forwarded-access-token")`; incluye además
# `streamlit.testing.v1.AppTest` para las pruebas funcionales de UI.
# Pin 1.67.0 acordado con el humano en la tarea 1.1 de C9: estable más
# reciente en PyPI (2026-11-05), requires_python >=3.11 sin techo, compatible
# a la vez con la imagen estándar de Databricks Apps (Python 3.11) y con el
# entorno local (Python 3.14.10). Instalado en ~/.venv con autorización
# expresa del humano.
streamlit==1.67.0

# (design.md D3/D6) y Statement Execution API para el SQL OBO del plano de
# datos (F2). Pin 0.170.0 heredado de C7, contrastado contra los workspaces
# reales en la capa integral; compartido con requirements-dev.txt.
databricks-sdk==0.170.0
